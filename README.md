# Interface Web — Élection UEH

Interface web statique du projet de gestion électorale.

## Modifications de cette version

- Aucun jeu de données fictif n'est injecté au chargement.
- Nouvelle identité visuelle dominée par le bleu et le rouge du drapeau haïtien, avec le doré comme couleur d'accent.
- Les données de la version navigateur restent locales (`localStorage`).
- La réinitialisation des données est une action manuelle et explicite.

## Utilisation

Ouvrir `index.html` dans un navigateur moderne.

## GitHub Pages

Déposer le contenu de ce dossier dans le dépôt publié par GitHub Pages. `index.html` est à la racine.
